# Prax Labs Cursor plugins

Marketplace repository for Prax Labs plugins for Cursor.

| Plugin | What it does |
| --- | --- |
| [`prax-screening`](plugins/prax-screening/) | Screen banks, wires, counterparties, countries, domains, IPs, securities, dependencies and wallets with Prax Data Services before you pay, sign, ship or onboard. |

Install from **Cursor Settings → Plugins** or with `/add-plugin prax-screening`. Each plugin folder has its own README.
